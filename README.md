# reorderable audio mixer

obs 33 changed how plugins are loaded. install into the new plugins folder or obs will mark the plugin as legacy and complain. the old way of installing plugins is being removed.

windows: extract the plugins-dir zip into %ProgramData%\obs-studio\plugins\

macos: run the pkg, or copy the .plugin into ~/Library/Application Support/obs-studio/plugins/

linux: deb is built but untested
